Convert Serein themes to Discord CSS, and back.

Drop a .serein-extension or a CSS file. Colors, background images, section opacity and sizes carry over in both directions. Everything runs in your browser.

Changelog

v1.10 latest

  • Language follows your browser. English, Russian or Ukrainian is chosen automatically; English is the fallback.
  • The language button cycles EN → RU → UK, and only a manual choice is remembered.
  • Ukrainian interface added.

v1.9

  • Style sliders. Transparency, blur, window radius and text sizes with a live preview.
  • Import by link. Paste a raw GitHub / jsDelivr link (also ?import=URL); @import files are followed.
  • Saved session. Your last input and options are restored after a reload.
  • Russian / English. Switch the interface language in the header.

v1.8

  • Proper favicon set. SVG, ICO, PNG and an Apple touch icon instead of an inline placeholder.

v1.7

  • Background image upload. Add your own wallpaper; it is embedded into the Serein file or the CSS.
  • Color editor. Click any swatch to change a color; the output and preview update.
  • Light preview. Dark / Light switch for the mockup and palette.
  • Batch mode. Select or drop several files at once and download them as a ZIP.
  • Smarter CSS parsing. Variable-less themes now also give section opacity, window radius and font size.
  • Favicon and link preview card for sharing the site.

v1.6

  • Themes without variables. CSS written as plain rules (no --name variables) is now converted: accent, text, link, hover, positive, warning and danger colors are picked by how often they appear.
  • Wallpaper. A background image URL in the CSS is downloaded and embedded when the host allows it.
  • Named colors (white, silver, gold…) are understood.

v1.5

  • New look. Dashed frames, corner nodes, orange accent and a dotted grid background.
  • Changelog button moved into the header as an orange pill.
  • Preview link now shows and opens extera.is-a.dev.

v1.4

  • Newer Discord variables. Recognizes --background-base-*, --background-surface-high and --text-default.
  • Parser fix. A last declaration without a trailing semicolon is no longer skipped.
  • Clearer errors. Shows which variables were found, or says the file has none.
  • Preview link now points to extera.is-a.dev.

v1.3

  • Fixed credit. Converted files always carry the made-by credit; the author field was removed.
  • Output panel is read-only.

v1.2

  • New design. Neutral dark theme with a light option, English interface.
  • Live preview. Discord mockup and palette built from the loaded theme.
  • Starts empty; the example loads on request.

v1.1

  • Full Serein support. Background and cover images, extra colors (hover, link, mention, positive, warning), per-section opacity, font sizes, spacing and window radius.
  • Standard Discord CSS output next to Discord Mica.
  • Lossless round trip between Serein and CSS.

v1.0

  • First release: Serein theme to Discord Mica CSS and back.
